For project support and bug reports, use the project's GitHub repository. Include the page you were using, the general type of file involved, and the error message you saw. Do not include private documents or API keys in a public issue.

Before contacting support

  • Try the operation again if a temporary processing error occurs.
  • Never share your CloudConvert API key in a support request.
